# Kizuku 0.2.0 Preview 4

- All ON, All OFF, and individual app switches apply access immediately. Choose temporary access from the app’s access menu. Remembered access follows the selected host.
- The Shizuku compatibility companion has no launcher icon. If it is already installed, open Settings → Compatibility companion → Update to replace it in place.
- Settings includes manual and opt-in daily update checks, optional automatic downloads, and links to the project and Buy Me a Coffee. Android asks before installing an update.
